# finestworksong.com (placeholder)

Static one-page placeholder for GitHub Pages. No build step.

- `index.html`: Vimeo embed and the email address.
- `better-than-fine-1/`: redirects to `/` so the old GoDaddy URL still works.
- `fonts/`: Cabin, self-hosted so visitors make no requests to Google.
- `CNAME`: custom domain for GitHub Pages.

Deploy: put these files at the top level of a GitHub repo, Settings > Pages > deploy from your default branch / root, then add the DNS records at GoDaddy.
